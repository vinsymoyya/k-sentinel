# Frozen experiment source

`source_snapshot/` preserves every source file identified by the v0.1.0 experiment's `config.json`, byte for byte. Their SHA256 values are checked before the released numerical results are verified. The live package may evolve; changes to its input validation or distribution do not retrospectively change the executed source or reported experiment. The v0.1.0 results, checkpoints, manuscript and release tag remain the historical experimental record.
